# tdasXDevin

Simulador visual interactivo de estructuras de datos con nodos (lista, pila, cola, lista doble, lista circular, árbol binario de búsqueda y grafo), con el código Java canónico de cada TDA resaltado mientras corre la animación.

## Correrlo

**Opción 1 — sin instalar nada:** abrir `index.html` en cualquier browser.

**Opción 2 — con Docker:**

```bash
docker build -t tdas .
docker run -p 8000:80 tdas
```

y abrir http://localhost:8000

**Opción 3 — docker compose:**

```bash
docker compose up
```

y abrir http://localhost:8000
